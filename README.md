## 📌 Sobre o Projeto
Este programa em Python foi desenvolvido para a empresa de marketing **TudoWeb** com o objetivo de coletar a opinião de clientes sobre o atendimento prestado.

## ⚙️ Funcionalidades
- Coleta de dados (Nome, Idade e Opinião) de 50 entrevistados através da estrutura de repetição `for`.
- Classificação do atendimento:
  - `1`: EXCELENTE
  - `2`: BOM
  - `3`: RUIM
- Contagem e exibição do total de respostas **EXCELENTE** e **RUIM** ao final do processo.

## 🚀 Como Executar
1. Certifique-se de ter o Python 3 instalado.
2. Clone o repositório ou faça o download dos arquivos.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   python app.py
   ```
